# TC-API-01c: 固定时钟没有第二条路径

| 属性 | 值 |
|------|-----|
| 编号 | TC-API-01c |
| 优先级 | P0 |
| 模块 | 时钟 |
| 平台 | Server |
| 关联需求 | 容器内 PHP 只读同一组 `LD_PRELOAD` / `FAKETIME` |
| 关联 CR | CR-1 竞态。无双路径，本条不发请求 |

## 前置条件

- 无。

## 操作步骤

1. 不发送业务请求。
2. 在 test-plan 把本条结果选为 N/A。

## 预期结果

- 不适用。签到、累充、活动窗口都调用进程里的 `time()` / `new DateTimeImmutable('now')`，没有第二套时钟入口可以同时打中。
- 多请求并发看到的是同一把假时钟，不属于 CR-1 要补的竞态。并发领取见 TC-PAY-06。

## 不应出现

- 为了凑四类，另起一个「两个客户端各看各的日期」的步骤。

## 备注

- 7.2 对 CR-1 没有单独的竞态行。本条只闭合「P0 修复四类」里的竞态格。
